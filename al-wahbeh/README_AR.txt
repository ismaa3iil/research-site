دليل نشر مستكشف شجرة نسب السادة الأشراف آل وهبة على الإنترنت
==============================================================

محتويات الحزمة:
1. index.html
   الصفحة الرئيسية الكاملة لتطبيق مستكشف شجرة آل وهبة التفاعلي (تعمل مباشرة دون الحاجة لخادم خلفي أو قاعدة بيانات).
2. downloads/al_wahbeh_genealogy.xlsx
   قاعدة بيانات الأنساب بصيغة إكسل البحثية (تدعم إضافة النساء والأمهات والملاحظات).
3. downloads/al_wahbeh_tree_and_history.pdf
   النسخة المطبوعة والمرسومة بالعربية للمشجرات والتراجم التاريخية الموثقة.
4. downloads/al_wahbeh_genealogy.ged
   ملف الأنساب القياسي بصيغة GEDCOM 5.5.1 لبرامج الأنساب العالمية.
5. downloads/al_wahbeh_genealogy.json
   نسخة احتياطية منظّمة لقاعدة البيانات بصيغة JSON.

طريقة النشر على الإنترنت (خطوة واحدة):
- عبر الاستضافة التقليدية (cPanel / Apache / Nginx):
  فكّ ضغط الملف وارفع ملف index.html (ومجلد downloads اختيارياً) إلى مجلد public_html أو إلى مجلد فرعي (مثلاً: /tree/).
- عبر الاستضافة السحابية المجانية (Netlify أو Cloudflare Pages أو GitHub Pages):
  اسحب المجلد بعد فكّ الضغط وأفلته مباشرة، وسيعمل الموقع فوراً باللغة العربية الكاملة.

ملاحظات تقنية:
- التطبيق يعتمد على ملف واحد متكامل (index.html) يحتوي على كامل بيانات الشجرة والتراجم والمراجع، ويحمّل خطوط Google العربية ومكتبتي Tailwind CSS وSheetJS عبر الإنترنت عند التصفح.
- أي إضافات أو تعديلات يجريها الزائر في المتصفح تُحفظ محلياً في جهازه (localStorage) ويمكن تصديرها كملف Excel أو GEDCOM أو SVG/PNG أو طباعتها كـ PDF.
