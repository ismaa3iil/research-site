# Triangle Physics Explorer — website integration

The files in this folder are the supplied deployable `dist/` contents, served at:

<https://ismaa3iil.fyi/physically-inspired-triangle-centers/explorer/>

No build step or backend is required. All runtime scripts, data, mathematical rendering assets, and fonts are bundled locally.

See [README.html](README.html) for numerical methods, evidence qualifications, and attribution. The original software uses the [MIT license](LICENSE); KaTeX has its bundled license, and ETC material retains its attribution.

The [source ZIP](Triangle_Physics_Explorer_Source.zip) and [complete receiving-team handoff](../Triangle_Physics_Explorer_GitHub_Handoff.zip) are freely downloadable. The handoff contains `build_data.py`, `verify.cjs`, and `verify_fingerprints.cjs`; regenerating the browser atlas requires the original research workspace.
