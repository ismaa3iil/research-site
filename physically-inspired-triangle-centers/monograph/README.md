# Triangle Centers Inspired by Physics — research monograph

Consolidated research edition, 3 October 2026, 274 pages.

- [Read or download the book](PITC_Monograph.pdf).
- [Download the monograph source and evidence](PITC_Monograph_Source_and_Evidence.zip).
- [Project page](https://ismaa3iil.fyi/physically-inspired-triangle-centers/).

The supplied PDF and ZIP are published byte for byte. The ZIP includes the same PDF, one editable LaTeX manuscript, its figures, selected evidence records, editorial and document audits, and an integrity manifest. Its README gives compilation instructions and explains the scientific evidence and reproduction requirements.

The monograph brings together six physics studies, a common introductory chapter, six thematic appendices, 159 images, a 66-entry center/evidence index, and 32 consolidated references. The research atlas remains separately available from the project page.

Extract the ZIP and run `python verify_manifest.py` from the extracted monograph folder to check the supplied package's integrity. Selected evidence files do not replace the separate six-chapter software environment required for full regeneration of the underlying studies. Original material and third-party references retain their existing rights.
