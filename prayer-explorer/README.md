# Prayer Time Model Explorer

Live application: https://ismaa3iil.fyi/prayer-explorer/

Interactive comparisons of fractional and angular prayer-time models for 2026–2030, with configurable horizon conventions, Makka reference calibration, shadow fits, geographic comparisons, and annual compatibility counts.

The browser entry point is index.html. Calculations are implemented in engine.js and the daily solar data are bundled in ephemeris.js. The full mathematical guide is in help.js and available inside the application.

Download Prayer_Time_Explorer.zip for the self-contained offline HTML application, editable project files, data-generation script, and regression checks. The source package README explains how to run the checks.

Research by Ismail Hammoudeh. The retained pvlib implementation used to generate the solar ephemeris is covered by third-party.txt.
